# Comments

The user opens `Comments` because conversation needs a place to be reviewed with care.

This desk should feel like a moderation queue, not a graveyard of raw messages. The user should see what is waiting, what was approved, what was rejected, what was marked as spam, and what still needs judgment. The screen should help the user notice patterns instead of drowning them in isolated rows.

A comment never exists alone. Context is the whole point. When the user clicks a comment, they should see the post it belongs to, the parent comment if there is one, the nearby thread, the person who wrote it, and any earlier moderation notes that matter. That context should be part of the desk, not hidden behind links the user has to chase.

Speed matters here, but so does care. The user should be able to process a queue quickly with bulk actions when the situation is obvious, but slow down and inspect details when a comment is borderline. The best moderation desk makes both of those modes feel natural.

The filters should reflect real moderation work: status, post, author, date, maybe suspicious phrases or repeated senders. And like every other desk, refresh should preserve the exact view. A moderator who narrowed a queue to one post and one status should come back to that same slice.

This desk should also tell a broader story. Are comments arriving from the live site? Are they piling up? Are certain posts drawing heavier discussion? Are there pending items that have been waiting too long? Those signals turn moderation from a reactive chore into a manageable habit.

Acting on a comment should feel explicit. Approve, reject, and spam should not be mysterious. If the user adds a moderation reason, they should know who can see it and why it matters. If the action succeeds, the queue should update confidently. If it fails, the user should know whether the comment stayed untouched or changed partially.

The best version of this desk makes the user feel in control of discussion quality. They are not just clearing tickets. They are protecting the tone and trust of the publication.

What would make the user happy:
- Every comment comes with enough context to make a good decision.
- Queue filters match real moderation habits.
- Bulk actions are safe when the answer is obvious.
- The desk shows backlog and attention signals clearly.
- Post and thread context are always close at hand.

What would make the user angry:
- Moderating blind, with no view of the surrounding conversation.
- Jumping through several screens just to inspect one questionable comment.
- Actions that feel irreversible or vague.
- No way to narrow a noisy queue properly.
- Losing place in the queue after refresh.
